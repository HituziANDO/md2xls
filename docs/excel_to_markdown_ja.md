# ExcelからMarkdownに変換する

ExcelブックをMarkdownに変換し、埋め込み画像を取り出します。

## コマンドの書式

```text
md2xls reverse [-c CONFIG] [-s INPUT.xlsx] [-d OUTPUT] [--image-dir DIRECTORY]
               [--sheet NAME | --all-sheets] [--split-sheets[=BOOL]]
               [--no-strip-heading-number] [--secrets FILE]
```

### オプション

| フラグ | 短縮形 | 既定値 | 説明 |
|------|-----------|---------|-------------|
| `--config` | `-c` | 作業ディレクトリの `.m2x.yml`。 | 設定ファイル。 |
| `--src` | `-s` | `reverse.src`、未設定ならトップレベルの `dst`（組み込み既定値：`README.xlsx`）。 | 入力するExcelブック。 |
| `--dst` | `-d` | `reverse.dst`。未設定なら入力の拡張子を `.md` に変更（1ファイル）、または除去（分割先ディレクトリ）します。 | 出力するMarkdownファイル。分割時は出力ディレクトリ。 |
| `--image-dir` |  | `reverse.image_dir`（組み込み既定値：作業ディレクトリの `./images`）。 | 画像の保存先。 |
| `--sheet` |  | `--all-sheets` がなければ既定値以外の `sheet_name` を使います。未指定または既定の `Sheet1` なら全ワークシートを変換します。 | 1シートだけ変換します。`--all-sheets` とは併用できません。 |
| `--all-sheets` |  | 上書きせず、`--sheet` の指定または上記の省略時の動作に従います。 | `sheet_name` の設定にかかわらず、全ワークシートをブック順に変換します。 |
| `--split-sheets` |  | `reverse.split_sheets`（組み込み既定値：`false`、1ファイル）。 | シートごとに1ファイルを出力します。設定で有効な分割を無効にするには `--split-sheets=false` を指定します。 |
| `--no-strip-heading-number` |  | `reverse.strip_heading_number`（組み込み既定値：`true`、番号を除去）。 | `1.` や `1.1.` などの見出し番号を残します。 |
| `--secrets` |  | トップレベルの `secrets`。未設定なら値を置き換えません。 | 値を `{{secret:NAME}}` に戻すためのYAMLファイル。 |

## シートと画像の出力

- **既定の出力：** 入力ファイルの拡張子を `.md` に変えたパスに、全ワークシートをブック順で1ファイルにまとめます。複数シートの場合はシート名が見出しになります。グラフシートは読み飛ばします。
- **シートの指定：** `--sheet シート名` で1シートを選びます。`--all-sheets` を指定すると、設定ファイルの `sheet_name` にかかわらず全ワークシートを出力します。
- **見出し番号：** 残す場合は `--no-strip-heading-number` を指定します。
- **画像：** 既定の保存先は作業ディレクトリの `./images` です。Markdownからは相対パスで参照します。同名の画像がある場合、内容が同じなら再利用し、異なる場合は `_2` などの連番を付けます。

## シートごとに1ファイルへ出力する

```sh
md2xls reverse --split-sheets --all-sheets -s 設計書.xlsx -d output/設計書
```

- **分割の指定：** `--split-sheets` または設定ファイルの `reverse.split_sheets: true` で有効にします。`--split-sheets=false` を指定すると1ファイルにまとめます。
- **出力ディレクトリ：** `-d` または `reverse.dst` で指定します。省略時は入力パスから拡張子を除いたディレクトリです。
- **ファイル名と画像：** 選択したシートごとに、ブック内の位置を番号にした `001_シート名.md` 形式で出力します。画像も画像保存先の下に同じ番号で分けて保存します。
- **Excelの再構築：** 複数ファイルから再構築すると、拡張子を除いたファイル名がシート名になります。番号や、ファイル名の禁止文字を置き換えた下線も残ります。たとえば `001_表紙.md` は `001_表紙` になります。

## 表・図・コードブロック

- **表：** 複数列の帳票は空行で表を分けます。罫線がない場合は、複数のセルに値がある行と、その前後に空行なしで続く行を1つの表にします。罫線付きの1列一覧も表になります。
- **図：** 図形のラベルと図形間の接続をMermaidのフローチャートに変換します。
- **注記付きスクリーンショット：** グループ化されたスクリーンショットと注記は1枚のSVGにまとめ、元の行位置に挿入します。
- **コードブロック：** 同じ単色の背景と列範囲が続き、各行の値が1セルに収まる範囲では、コマンド・設定行・端末出力を検出するとフェンス付きコードブロックにします。範囲内の空行・空白・セル内改行は保持します。
- **表とコード例の区切り：** 表と独立したコード例の間には空行を入れてください。

## コードブロックの判定条件を追加する

`.m2x.yml` の `reverse.code_blocks` に指定します。どちらも省略でき、組み込み条件と併用できます。

- `line_patterns`：Goの正規表現を指定し、前後の空白を除いた行に照合します。領域内の1行でも一致すれば、色付き領域全体をコードブロックにします。
- `fill_colors`：白以外の6桁のRGB値を指定します。背景が指定の単色に一致する領域は、内容にかかわらずコードブロックにします。

```yaml
reverse:
  code_blocks:
    line_patterns:
      - '^mytool(\s|$)'
    fill_colors:
      - '#E2F0D9'
```

## 秘密値を名前に戻す

`--secrets FILE`（または `.m2x.yml` の `secrets: FILE`）を指定すると、[値のファイル](./README_ja.md#秘密値の差し込み)にある値を `{{secret:NAME}}` としてMarkdownに書き出します。`md2xls --secrets` で作ったブックを、値の無いMarkdownに戻せます。

```sh
md2xls reverse --secrets secrets.yml -s design.xlsx -d design.md
```

- **置き換えの順序：** 長い値から先に置き換えます。ある値が別の値の一部になっていても、長い方の値が分断されません。
- **同じ値：** 同じ値が複数の名前にある場合は、名前の辞書順で最初のものを使い、該当する名前を警告に出します。
- **名前：** 英数字と `.`・`_`・`-` 以外の文字を含む名前は参照に使えません。値は置き換えますが、その参照はExcelへ変換できないため、名前の変更を促す警告を出します。
- **短い値：** `-` や `993` のような4文字未満の値は、関係のない箇所に一致するため置き換えません。該当する名前を警告に出し、値はMarkdownに残ります。
- **結果の表示：** 名前ごとの置き換えた回数を標準エラーに出します。警告とこの表示に含まれるのは名前、ファイル名、回数だけで、値は含みません。
- **一致の範囲：** ブック内の文字列のうち値と一致する箇所は、参照から差し込まれたものでなくても、すべて参照に置き換えます。
- **文字どおりの記述：** ブック内にもともと `{{secret:` と書かれている箇所は、`--secrets` の有無にかかわらず、バックスラッシュを付けて `\{{secret:` と書き出します。そのMarkdownをもう一度Excelに変換しても、文字列のまま残ります。

制限：

- 画像の中の値は置き換えません。取り出したSVGの中に値が見つかった場合は、ファイル名と名前を警告に出します（SVGの中身は書き換えません）。PNGなどのビットマップ画像の中の値は検出しません。
- 値は、1つのセルに全体が入っている場合にだけ認識します。Excelへの出力では値を行の途中で分割しません。Excel上で手作業で分割された値は、Markdownに値のまま残ります。
- リスト項目や番号付きの見出しのように始まる値（`1. text` など）だけの段落は、その要素として読み取るため、値がMarkdownに残ります。
- Excel上で編集された値は一致しなくなり、Markdownに値のまま残ります。コミットの前に、出力したMarkdownを `md2xls secrets check` で確認してください。

## 変換の制約

- 逆変換には、Excelに保存されたセルの値と書式を使います。
- Excelへ出力すると、コードブロックの言語名とHTMLコメントは失われます。
- 外部リンクはセルのテキスト全体に付きます。同じブック内のセルへのリンクは表示テキストだけを出力します。
