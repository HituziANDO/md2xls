# ExcelからMarkdownに変換する

ExcelブックをMarkdownに変換し、埋め込み画像を取り出せます。複数列の帳票は空行ごとに表に分け、図形に記載された文字と図形間の接続はMermaidのフローチャートに変換します。スクリーンショットと注記をグループ化した画面レイアウトは、画像と注記を重ねたSVGとして元の行位置に挿入します。

```sh
md2xls reverse -s sample/output/demo.xlsx -d sample/output/demo.md --image-dir sample/output/images
```

既定設定では全ワークシートをブック順に1ファイルへ出力します。グラフシートは読み飛ばします。複数シートの場合はシート名が見出しになります。`--sheet シート名` で1枚を選択でき、`--all-sheets` で設定ファイルの `sheet_name` にかかわらず全シートを選択できます。出力先の既定値は、入力ファイルの拡張子を `.md` に変えたパスです。画像は既定で作業ディレクトリの `./images` に保存し、Markdownからの相対パスで参照します。保存先に同名の画像がある場合、内容が同じなら再利用し、異なる場合は `_2` などの連番を付けて保存します。見出し番号を残すには `--no-strip-heading-number` を指定します。

`--split-sheets` を指定すると、対象シートごとにMarkdownを保存します。この場合の `-d`（または `reverse.dst`）は出力ディレクトリです。省略時は入力パスから拡張子を除いたディレクトリを使います。ファイル名はブック内の順番に `001_シート名.md` となり、画像も画像保存先の下に同じ番号で分けて保存します。複数ファイルから再構築すると、連番やファイル名の禁止文字を置き換えた下線もシート名に含まれます。例として `001_表紙.md` のシート名は `001_表紙` です。

```sh
md2xls reverse --split-sheets --all-sheets -s 設計書.xlsx -d output/設計書
```

設定ファイルでは `reverse.split_sheets: true` で分割を有効にできます。コマンドラインで `--split-sheets=false` を指定すると1ファイルにまとめます。

同じ背景色と列範囲が続き、各行の値が1セルに収まる場合、コマンド・設定行・端末出力を手掛かりにコードブロックとしてまとめます。範囲内の空行・空白・セル内改行を保持します。罫線のない表では、複数のセルに値がある行と、空行を挟まずに続く前後の行を1つの表にします。表と独立したコード例の間には空行を入れてください。罫線付きの1列一覧も表として扱います。

ドキュメントごとの判定条件は `.m2x.yml` の `reverse.code_blocks` に追加できます。`line_patterns` はGoの正規表現で、前後の空白を除いた行に照合します。領域内の1行でも一致すれば、領域全体をコードブロックにします。`fill_colors` はコード専用の背景色を白以外の6桁のRGB値で指定します。指定色の領域は内容を問わず対象になります。どちらも省略でき、組み込み条件と併用されます。

```yaml
reverse:
  code_blocks:
    line_patterns:
      - '^mytool(\s|$)'
    fill_colors:
      - '#E2F0D9'
```

逆変換にはExcelに保存されたセルの値と書式を使います。コードブロックの言語名とHTMLコメントはExcel出力時に失われます。外部リンクはセルのテキスト全体に付きます。同じブック内のセルへのリンクは、表示テキストとして出力します。
